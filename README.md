# 🎨 만화 필터 — 내 컴퓨터에서 돌리는 판

> 이 브랜치(`local`)는 **자기 컴퓨터에서 돌리는 사람**을 위한 것입니다.
> 무료 호스팅의 좁은 램·CPU에 맞출 이유가 없으니, 화질과 장수를 넉넉하게
> 잡아 두었습니다. 서버에 올릴 거라면 배포 설정이 들어 있는
> `claude/image-cartoon-styles-qe61x7` 브랜치를 쓰세요.

사진을 올리면 열두 가지 그림풍 스타일로 바꿔 주는 웹 앱입니다.
OpenCV만 쓰기 때문에 별도 모델이나 API 없이 내 컴퓨터에서 돌아가고,
사진이 인터넷으로 나가지 않습니다.

## 시작하기 (한 줄)

파이썬 3.9 이상만 깔려 있으면 됩니다.

```bash
git clone -b local <저장소 주소>
cd Filter-Transformation
python run.py            # 윈도우도 같은 명령
```

`run.py`가 알아서 다 합니다.

1. 가상환경(`.venv`)을 만들고 필요한 것을 설치합니다 — 처음 한 번만 몇 분
2. 이 컴퓨터의 코어 수를 보고 설정을 잡습니다
3. 서버를 띄우고 브라우저를 엽니다

끄려면 그 창에서 <kbd>Ctrl</kbd>+<kbd>C</kbd>. 두 번째부터는 설치 과정 없이 바로 뜹니다.

### 이 브랜치가 다르게 잡아 둔 값

| 설정 | 로컬(이 브랜치) | 무료 호스팅용 |
|---|---|---|
| 처리 해상도 | **2000px** | 1000px |
| 동시 변환 | **코어 수 ÷ 2 (최대 4장)** | 1장 |
| 일괄 업로드 | **200장** | 12장 |
| 장당 용량 | **64MB** | 8MB |
| 결과 보관 | **6시간** | 30분 |

4코어 노트북에서 2000×2000 사진 한 장을 열두 스타일로 바꾸는 데 15초 안팎입니다.
더 빠르게 보고 싶으면 해상도를 낮추면 됩니다.

```bash
CARTOON_MAX_SIDE=1200 python run.py      # 윈도우: set CARTOON_MAX_SIDE=1200
```

아래 [설정](#설정-환경변수)의 값은 모두 환경변수로 덮어쓸 수 있습니다.
`run.py`는 이미 정해져 있는 환경변수를 건드리지 않습니다.

## 스타일

| 키 | 이름 | 어떻게 만드나 | 색상 수 조절 |
|---|---|---|---|
| `soft` | 소프트 | `cv2.stylization` — 수채화처럼 부드럽게 번지는 느낌 | ✕ |
| `blobby` | 블로비 | Mean-shift + 색상 양자화 — 뭉텅한 스티커 느낌 | ○ (기본 12색) |
| `poster` | 포스터 | Bilateral + 색상 양자화 — 납작한 포스터 느낌 | ○ (기본 7색) |
| `ink` | 잉크 | 적응형 이진화 윤곽선 + 색상 양자화 — 만화책 느낌 | ○ (기본 10색) |
| `pop` | 팝아트 | 채도 부스트 + 5색 양자화 + 굵은 윤곽선 | ○ (기본 5색) |
| `oil` | 유화 | 주변에서 가장 흔한 밝기의 색으로 뭉개는 붓자국 | ○ (기본 8단계) |
| `halftone` | 하프톤 | 22° 기울인 격자에 밝기만큼 커지는 색점 | ○ (기본 8색) |
| `neon` | 네온 | 어두운 배경 + 시안·마젠타로 물든 형광 윤곽선 | ✕ |
| `pixel` | 픽셀 | 가로 140칸으로 줄여 색을 묶고 그대로 확대 | ○ (기본 16색) |
| `horror` | 호러 | 채도 제거 + 푸른 색조 + 헐레이션 + 비네트 + 그레인 | ✕ |
| `pencil` | 연필 | 닷지 기법 연필선 + 옅은 음영 레이어 | ✕ |
| `crayon` | 색연필 | 옅게 칠한 색 위에 닷지 연필선을 곱하기 | ✕ |

색상 수 조절이 결과를 바꾸지 않는 스타일은 서버에서 자동으로 기본값으로 눕혀서,
같은 그림을 쓸데없이 다시 만들지 않습니다.

## 직접 띄우고 싶다면

`run.py`를 거치지 않고 손으로 해도 됩니다.

```bash
python3 -m venv .venv
source .venv/bin/activate          # 윈도우: .venv\Scripts\activate
pip install -r requirements.txt

python app.py                      # http://127.0.0.1:5000
```

이때는 기본값(해상도 1400, 동시 1장)으로 뜹니다. `run.py`가 잡아 주는
로컬용 값을 쓰려면 환경변수를 직접 넘기세요.

### 같은 집 안의 다른 기기에서 열기

휴대폰으로 찍은 사진을 바로 올리고 싶을 때 씁니다.

```bash
HOST=0.0.0.0 python run.py
```

그다음 컴퓨터의 내부 IP(`192.168.x.x`)로 접속합니다. 공유기 안에서만 열리지만,
같은 와이파이를 쓰는 사람은 누구나 들어올 수 있으니 필요할 때만 켜세요.

## 사용법

웹에는 두 가지 모드가 있습니다.

### 한 장 비교 — 사진 하나를 열두 가지 스타일로

1. 사진을 드래그해서 놓거나, 영역을 클릭해 고르거나, <kbd>Ctrl</kbd>+<kbd>V</kbd>로 붙여넣습니다.
2. 열두 가지 스타일이 순서대로 변환되고, 끝난 것부터 카드에 채워집니다.
3. **색상 수**를 바꾸면 영향을 받는 일곱 스타일만 다시 그려집니다. (`자동`은 스타일별 기본값)
4. 카드의 **저장** 버튼으로 한 장씩, **전체 다운로드**로 열두 장을 zip으로 받습니다.

### 여러 장 한 번에 — 폴더째 올려서 원하는 스타일로

1. 사진 여러 장을 끌어다 놓거나, **폴더 고르기**로 폴더를 통째로 지정합니다.
   폴더 안의 이미지가 아닌 파일과 용량 초과 파일은 알아서 걸러집니다.
2. 적용할 스타일을 고릅니다. 여러 개를 골라도 되고, **전체 선택**도 있습니다.
3. **변환 시작**을 누르면 사진 × 스타일만큼 순서대로 변환되며 결과가 하나씩 채워집니다.
4. **zip 다운로드**로 전부 받습니다. 스타일을 둘 이상 골랐으면 스타일별 폴더로 나눠 담깁니다.

```
5장_cartoon.zip
├── soft/    사진1_soft.jpg, 사진2_soft.jpg …
└── pop/     사진1_pop.jpg,  사진2_pop.jpg  …
```

한 번에 올릴 수 있는 장수는 기본 40장이고 `CARTOON_MAX_BATCH_FILES`로 바꿉니다.
파일은 한 장씩 따로 올라가므로 용량 제한은 요청당이 아니라 **장당** 걸립니다.
변환은 순서대로 한 장씩 처리합니다 — 사진 40장에 스타일 12개면 480장이라
몇 분 걸리므로, 총 장수가 40장을 넘으면 예상 시간을 미리 알려 줍니다.

입력 이미지는 긴 변이 1400px(`CARTOON_MAX_SIDE`)을 넘으면 자동으로 줄여서
처리합니다. 1400×1050 기준으로 열두 장을 모두 만드는 데 5초 안팎,
1000×750으로 낮추면 3초 안팎이 걸립니다.

### 풍경 사진에서 무너지던 것들

인물이나 근접 사진에서는 멀쩡하다가 하늘·잔디처럼 넓고 매끈하거나
결이 촘촘한 면에서 무너지는 필터가 셋 있었습니다.

- **네온**: 고정 임계값으로 윤곽선을 따다 보니 잔디에서는 화면 전체가 선이 되어
  통째로 발광했습니다. 이제 결을 먼저 눌러 놓고, 그라디언트 분위수로
  상위 6%만 선으로 남깁니다. 합성도 더하기 대신 스크린으로 바꿔
  밝은 부분이 255에서 뭉개지지 않습니다.
- **연필·색연필**: `cv2.pencilSketch`를 쓰다가 아예 걷어냈습니다. 국소 대비를
  키우는 필터라 매끈한 하늘은 흰 여백이 되고, 나뭇잎처럼 잔결이 촘촘한 곳은
  획이 겹쳐 새까맣게 뭉쳤습니다. 잔디 사진은 화면의 91%가 검게 나왔습니다.
  지금은 흑백을 뒤집어 흐린 것으로 나누는 **닷지 기법**을 씁니다. 밝기 차가
  생긴 자리에만 획이 남아 아무리 결이 촘촘해도 메워지지 않습니다(91% → 0.3%).
  대신 획이 너무 옅어지므로, 그은 자리만 골라 진하게 만드는 배수를 따로 둡니다
  (연필 2.0배, 색연필 3.5배). 획 굵기는 사진 크기에 비례시켜
  큰 사진에서도 같은 인상이 나옵니다.
  연필에는 밝기에 따른 옅은 음영을 곱해 빈 종이가 남지 않게 했고,
  색연필은 옅게 칠한 색 레이어 위에 그 획을 곱해 얹습니다.

**팝아트**는 잔디·털처럼 결이 촘촘한 곳에서 짧은 선 조각이 검은 점처럼
사방에 뿌려졌습니다. 결을 먼저 누른 뒤 선을 따고, 이어진 덩어리가
일정 크기를 넘는 것만 남기도록 바꿔서 굵은 외곽선만 살아남게 했습니다.
선 굵기는 3px에서 2px로 낮췄습니다.

**하프톤**은 망점이 커 보인다는 의견을 받아 한 칸 크기를 긴 변의 1/90에서
1/150로 줄였습니다. (1400px 기준 16px → 9px)

### 속도

원래 병목은 색상 양자화와 mean-shift 두 군데였습니다.

- **양자화**: 모든 픽셀로 k-means를 돌리는 대신 8만 픽셀만 고르게 뽑아 중심을 학습하고,
  배정은 행렬 곱 한 번으로 전체 픽셀에 합니다. (k=12 기준 3.6초 → 0.7초)
- **블로비**: mean-shift는 해상도에 급격히 민감해서, 700px로 줄여 돌린 뒤 되돌립니다.
  어차피 색을 뭉개는 필터라 눈에 띄는 차이가 없습니다. (10.2초 → 1.6초)

열 스타일 전체로는 28.4초에서 7.8초가 됐습니다.
(스타일이 열둘로 늘어난 지금은 9.0초입니다.)

## 저장 구조

한 번의 작업(=토큰)이 이미지를 여러 장 담습니다. 한 장짜리 변환은 장이 하나뿐인
작업일 뿐이라 두 모드가 같은 저장·조회 경로를 씁니다.

```
{token}_meta.json                  {"stems": ["사진1", "사진2"], "created": …}
{token}_{i}_src.jpg                i번째 원본(CARTOON_MAX_SIDE로 축소한 것)
{token}_{i}_{style}-{colors}.jpg   변환 결과 (같은 요청이 다시 오면 그대로 재사용)
```

## CLI

웹 없이 폴더 단위로 일괄 변환할 수도 있습니다.

```bash
python cartoonize.py photos/ -o out/ -s all      # 열두 스타일 전부
python cartoonize.py a.jpg -s neon               # 한 장, 네온 스타일만
```

## 화면 색

색은 전부 CSS 변수로만 씁니다. `style.css` 맨 위 `:root` 토큰의 값만 바꾸면
전체 톤이 따라 바뀌고, 개별 규칙에는 색을 직접 적지 않습니다.
운영체제가 어두운 테마여도 이 앱은 항상 밝은 화면으로 보입니다.

## 설정 (환경변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `5000` | 서버 포트 |
| `HOST` | `127.0.0.1` | 바인딩 주소 |
| `CARTOON_MAX_SIDE` | `1400` (run.py는 2000) | 처리 해상도(긴 변). 낮추면 그만큼 빨라짐 |
| `CARTOON_CONCURRENCY` | `1` (run.py는 코어÷2) | 한 번에 요청할 변환 수 |
| `CARTOON_MAX_UPLOAD_MB` | `16` (run.py는 64) | 장당 업로드 용량 상한 |
| `CARTOON_MAX_BATCH_FILES` | `40` (run.py는 200) | 일괄 변환에 올릴 수 있는 장수 |
| `CARTOON_MAX_AGE_SECONDS` | `3600` (run.py는 21600) | 임시 파일 보관 시간(초) |
| `CARTOON_WORKDIR` | `$TMPDIR/cartoon_web` | 임시 파일 위치 |
| `CARTOON_DEBUG` | (없음) | 값을 주면 Flask 디버그 모드 |
| `CARTOON_NO_BROWSER` | (없음) | 값을 주면 run.py가 브라우저를 열지 않음 |

## 서버에 올리고 싶다면

이 브랜치는 로컬 전용이라 무료 호스팅용 설정(`render.yaml`)을 빼 두었습니다.
배포 설정과 그 문서는 `claude/image-cartoon-styles-qe61x7` 브랜치에 있습니다.

```bash
git checkout claude/image-cartoon-styles-qe61x7
```

필터 코드(`cartoon.py`)와 화면은 두 브랜치가 같습니다. 다른 것은 기본값과
실행 방법뿐입니다.

## 이미지 보관

업로드한 원본과 변환 결과는 이 컴퓨터의 임시 디렉터리에만 저장되고,
새 업로드가 들어올 때 여섯 시간이 지난 파일이 자동으로 삭제됩니다.
`CARTOON_MAX_AGE_SECONDS`로 보관 시간을, `CARTOON_WORKDIR`로 위치를 바꿉니다.

사진은 인터넷으로 나가지 않습니다. 브라우저와 서버가 같은 컴퓨터 안에 있고,
바깥으로 무엇도 보내지 않습니다.
