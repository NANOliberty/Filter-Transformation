# 🎨 만화 필터

사진을 올리면 열두 가지 그림풍 스타일로 바꿔 주는 웹 앱입니다.
OpenCV만 쓰기 때문에 별도 모델이나 API 없이 서버 한 대로 돌아가고,
CLI로 돌린 결과와 웹에서 받은 결과가 동일합니다.

## 스타일

| 키 | 이름 | 어떻게 만드나 | 색상 수 조절 |
|---|---|---|---|
| `soft` | 소프트 | `cv2.stylization` — 수채화처럼 부드럽게 번지는 느낌 | ✕ |
| `blobby` | 블로비 | Mean-shift + 색상 양자화 — 뭉텅한 스티커 느낌 | ○ (기본 12색) |
| `poster` | 포스터 | Bilateral + 색상 양자화 — 납작한 포스터 느낌 | ○ (기본 7색) |
| `ink` | 잉크 | 적응형 이진화 윤곽선 + 색상 양자화 — 만화책 느낌 | ○ (기본 10색) |
| `pop` | 팝아트 | 채도 부스트 + 5색 양자화 + 굵은 윤곽선 | ○ (기본 5색) |
| `oil` | 유화 | 주변에서 가장 흔한 밝기의 색으로 뭉개는 붓자국 | ○ (기본 8단계) |
| `halftone` | 하프톤 | 22° 기울인 격자에 밝기만큼 커지는 색점 | ○ (기본 8색) |
| `neon` | 네온 | 어두운 배경 + 시안·마젠타로 물든 형광 윤곽선 | ✕ |
| `pixel` | 픽셀 | 가로 80칸으로 줄여 색을 묶고 그대로 확대 | ○ (기본 16색) |
| `horror` | 호러 | 채도 제거 + 초록 색조 + 헐레이션 + 비네트 + 그레인 | ✕ |
| `pencil` | 연필 | 연필선 + 옅은 음영 레이어 | ✕ |
| `crayon` | 색연필 | 옅게 칠한 색 위에 연필선을 곱하기 | ✕ |

색상 수 조절이 결과를 바꾸지 않는 스타일은 서버에서 자동으로 기본값으로 눕혀서,
같은 그림을 쓸데없이 다시 만들지 않습니다.

## 실행

```bash
python3 -m venv .venv
source .venv/bin/activate          # 윈도우: .venv\Scripts\activate
pip install -r requirements.txt

python app.py                      # http://127.0.0.1:5000
```

`PORT`, `HOST` 환경변수로 주소를 바꿀 수 있습니다.

## 사용법

웹에는 두 가지 모드가 있습니다.

### 한 장 비교 — 사진 하나를 열두 가지 스타일로

1. 사진을 드래그해서 놓거나, 영역을 클릭해 고르거나, <kbd>Ctrl</kbd>+<kbd>V</kbd>로 붙여넣습니다.
2. 열두 가지 스타일이 순서대로 변환되고, 끝난 것부터 카드에 채워집니다.
3. **색상 수**를 바꾸면 영향을 받는 일곱 스타일만 다시 그려집니다. (`자동`은 스타일별 기본값)
4. 카드의 **저장** 버튼으로 한 장씩, **전체 다운로드**로 열두 장을 zip으로 받습니다.

### 여러 장 한 번에 — 폴더째 올려서 원하는 스타일로

1. 사진 여러 장을 끌어다 놓거나, **폴더 고르기**로 폴더를 통째로 지정합니다.
   폴더 안의 이미지가 아닌 파일과 용량 초과 파일은 알아서 걸러집니다.
2. 적용할 스타일을 고릅니다. 여러 개를 골라도 되고, **전체 선택**도 있습니다.
3. **변환 시작**을 누르면 사진 × 스타일만큼 순서대로 변환되며 결과가 하나씩 채워집니다.
4. **zip 다운로드**로 전부 받습니다. 스타일을 둘 이상 골랐으면 스타일별 폴더로 나눠 담깁니다.

```
5장_cartoon.zip
├── soft/    사진1_soft.jpg, 사진2_soft.jpg …
└── pop/     사진1_pop.jpg,  사진2_pop.jpg  …
```

한 번에 올릴 수 있는 장수는 기본 40장이고 `CARTOON_MAX_BATCH_FILES`로 바꿉니다.
파일은 한 장씩 따로 올라가므로 용량 제한은 요청당이 아니라 **장당** 걸립니다.
변환은 순서대로 한 장씩 처리합니다 — 사진 40장에 스타일 12개면 480장이라
몇 분 걸리므로, 총 장수가 40장을 넘으면 예상 시간을 미리 알려 줍니다.

입력 이미지는 긴 변이 1400px을 넘으면 자동으로 줄여서 처리합니다.
1400×1400 기준으로 열두 장을 모두 만드는 데 9초 안팎이 걸립니다.

### 풍경 사진에서 무너지던 것들

인물이나 근접 사진에서는 멀쩡하다가 하늘·잔디처럼 넓고 매끈하거나
결이 촘촘한 면에서 무너지는 필터가 셋 있었습니다.

- **네온**: 고정 임계값으로 윤곽선을 따다 보니 잔디에서는 화면 전체가 선이 되어
  통째로 발광했습니다. 이제 결을 먼저 눌러 놓고, 그라디언트 분위수로
  상위 6%만 선으로 남깁니다. 합성도 더하기 대신 스크린으로 바꿔
  밝은 부분이 255에서 뭉개지지 않습니다.
- **연필**: `pencilSketch`는 국소 대비를 키우는 필터라 매끈한 하늘은 흰 여백으로,
  잔결이 있는 하늘은 노이즈 덩어리로 만들었습니다. 미리 살짝 눌러 잡티를 없애고,
  밝기에 따른 옅은 음영을 곱해 빈 종이가 남지 않게 했습니다.
- **색연필**: `pencilSketch`의 컬러 출력 대신, 옅게 칠한 색 레이어에
  연필선을 곱해 얹습니다. 하늘색이 살아나고 선도 더 잘 보입니다.

**팝아트**는 잔디·털처럼 결이 촘촘한 곳에서 짧은 선 조각이 검은 점처럼
사방에 뿌려졌습니다. 결을 먼저 누른 뒤 선을 따고, 이어진 덩어리가
일정 크기를 넘는 것만 남기도록 바꿔서 굵은 외곽선만 살아남게 했습니다.

**하프톤**은 망점이 커 보인다는 의견을 받아 한 칸 크기를 긴 변의 1/90에서
1/150로 줄였습니다. (1400px 기준 16px → 9px)

### 속도

원래 병목은 색상 양자화와 mean-shift 두 군데였습니다.

- **양자화**: 모든 픽셀로 k-means를 돌리는 대신 8만 픽셀만 고르게 뽑아 중심을 학습하고,
  배정은 행렬 곱 한 번으로 전체 픽셀에 합니다. (k=12 기준 3.6초 → 0.7초)
- **블로비**: mean-shift는 해상도에 급격히 민감해서, 700px로 줄여 돌린 뒤 되돌립니다.
  어차피 색을 뭉개는 필터라 눈에 띄는 차이가 없습니다. (10.2초 → 1.6초)

열 스타일 전체로는 28.4초에서 7.8초가 됐습니다.
(스타일이 열둘로 늘어난 지금은 9.0초입니다.)

## 저장 구조

한 번의 작업(=토큰)이 이미지를 여러 장 담습니다. 한 장짜리 변환은 장이 하나뿐인
작업일 뿐이라 두 모드가 같은 저장·조회 경로를 씁니다.

```
{token}_meta.json                  {"stems": ["사진1", "사진2"], "created": …}
{token}_{i}_src.jpg                i번째 원본(1400px로 축소한 것)
{token}_{i}_{style}-{colors}.jpg   변환 결과 (같은 요청이 다시 오면 그대로 재사용)
```

## CLI

웹 없이 폴더 단위로 일괄 변환할 수도 있습니다.

```bash
python cartoonize.py photos/ -o out/ -s all      # 열두 스타일 전부
python cartoonize.py a.jpg -s neon               # 한 장, 네온 스타일만
```

## 화면 색

색은 전부 CSS 변수로만 씁니다. `style.css` 맨 위 `:root` 토큰의 값만 바꾸면
전체 톤이 따라 바뀌고, 개별 규칙에는 색을 직접 적지 않습니다.
운영체제가 어두운 테마여도 이 앱은 항상 밝은 화면으로 보입니다.

## 설정 (환경변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `5000` | 서버 포트 |
| `HOST` | `127.0.0.1` | 바인딩 주소 |
| `CARTOON_MAX_UPLOAD_MB` | `16` | 장당 업로드 용량 상한 |
| `CARTOON_MAX_BATCH_FILES` | `40` | 일괄 변환에 한 번에 올릴 수 있는 장수 |
| `CARTOON_MAX_AGE_SECONDS` | `3600` | 임시 파일 보관 시간 |
| `CARTOON_WORKDIR` | `$TMPDIR/cartoon_web` | 임시 파일 위치 |
| `CARTOON_DEBUG` | (없음) | 값을 주면 Flask 디버그 모드 |

## 배포

`python app.py`의 개발 서버 대신 gunicorn을 씁니다. 변환은 CPU를 오래 쓰므로
타임아웃을 넉넉히 잡고, 워커 수는 코어 수에 맞춥니다.

```bash
gunicorn -w 2 --threads 2 --timeout 120 -b 0.0.0.0:$PORT app:app
```

Render·Railway·Fly 등에서는 저장소의 `Procfile`이 그대로 쓰입니다.
`opencv-python-headless`를 쓰므로 GUI 라이브러리 없이도 설치됩니다.
